# My One and Only Bebe Pawie 💗

A personalized romantic message card made with HTML, CSS, and JavaScript, featuring Pawie’s photo, a soft pastel design, and animated hearts.

## Files
- `index.html` — card structure and message
- `style.css` — colors, layout, and animations
- `script.js` — interactive effects
- `photo.jpg` — photo displayed on the card

## How to use
Keep all four files in the same folder, then open [`index.html`](https://justinesumayang022107-bot.github.io/Digital-LETTER-for-you-my-Love/) in a web browser.
